# Дані гри «7 ланосів»

## Джерело

UCI Machine Learning Repository, набір **339**: «Taxi Service Trajectory — Prediction Challenge,
ECML PKDD 2015». Ліцензія CC BY 4.0. https://archive.ics.uci.edu/dataset/339

Архів лежить у git частинами `data/porto/porto_uci.zip.part00` … `part05` (534 065 916 байт,
SHA-256 `a33e2a5e…1f8c76`, повний хеш у `pipeline/raw.py`). Усередині `train.csv.zip` з 1 710 670
поїздок таксі міста Порту (липень 2013 – червень 2014). Файл `train.csv` (~1,9 ГБ) ніколи не
пишеться на диск, його читають потоком.

## Що ми беремо

Один тиждень: **пн 12.05.2014 00:00 — пн 19.05.2014 00:00** (за часом Europe/Lisbon, права
межа не входить). Поїздки з `MISSING_DATA = True` відкидаємо. Лишається 32 833 рядки у
`data/work/week.csv`; з них 26 802 проходять фільтр гри (`geo.trip_ok`: 4–240 точок, усі всередині
мапи, шлях 0,8–30 км, крок до 625 м, відстань по прямій від 0,3 км). З цього тижня
виходить 28 змін (4 слоти на добу: 08–10, 12–14, 17–19, 22–24).

## Команди, по черзі

З кореня репозиторію, з активним venv. Час виміряно на Mac, дані вже розпаковані.

| Крок | Команда | Результат | Час |
|---|---|---|---|
| 1 | `python -m pipeline.week` | `data/work/week.csv` | ~12 с; перший запуск ще склеює й розпаковує архів, разом ~75 с |
| 2 | `python -m pipeline.shifts --week data/work/week.csv` | `game/game_data.json` (3,4 МБ) | ~5 с |
| 3 | `python -m pipeline.roads --week data/work/week.csv` | `game/roads.json` (166 КБ), `data/work/roads_debug.png` | ~8 с |
| 4 | `python -m pipeline.build_game` | `game/index.html`, один офлайн-файл | < 1 с |

Результати детерміновані: два запуски дають однакові байти (`game_data.json`, `roads.json`).
Перевірка якості: `ruff check pipeline tests tools && python tools/check_py.py && pytest -q`.

## Що з цього справжні дані, а що модель гри

| Дані (рахує наш Python із сирого архіву) | Модель гри (вигадали ми) |
|---|---|
| поїздки, водії, маршрути, привид (найкращий справжній водій зміни), рейтинг, медіана й топ-10 %, гарячі точки, хвилі попиту, граф доріг | тариф 3,25 + 0,50 €/км (×1,2 вночі), час ×40, випередження й радіус пінів, чайові, комбо, типи пасажирів, 7 ШІ-суперників, медалі |

Звідки береться кожне поле: замовлення — справжні поїздки зміни (`pipeline/shifts.py`); водії
й рейтинг — суми тарифів справжніх водіїв зміни; гарячі точки й хвилі попиту — з точок
посадки (`pipeline/places.py`); граф доріг — з GPS-слідів тижня (`pipeline/roads.py`). Тариф
рахується нашою формулою з довжини справжнього маршруту, тому гроші у грі — модель, а не
справжні чеки. Екран «Про дані» у грі показує той самий поділ.
