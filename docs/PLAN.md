## Хто що робить

- **Ярослав:** Y1 ✅ → Y2 граф доріг (`pipeline/roads.py`, `game/roads.json`) → Y3 якість Python і `docs/DATA.md`. Від M2 до M3 `pipeline/`, `tests/` і `tools/*.py` редагує тільки Ярослав.
- **Артем:** A1 звук → A2 симулятор балансу (`pipeline/balance.py`, після C1, на `game/game_data.json`) → A3 README і `docs/DEMO.md`. На C1 і C2 — перевірка на справжньому телефоні зі звуком.
- **Кирило (хаб з агентами):** K1–K11, злиття, гейти, перевірки.

## Умова: Python ≥ 50 % коду

- Python — щонайменше половина коду репо за байтами, як рахує мовна смужка GitHub (Python проти JS + CSS + HTML; JSON, Markdown і `data/` не рахуються; `dist/` позначено як згенероване).
- Усе, що можна порахувати офлайн, робимо в Python (`pipeline/`, `tools/*.py`). JS у браузері лише грає: коротко, без мертвого коду.
- Перевірка: `python tools/lang_share.py` (з'явиться в main найближчим часом; падає, якщо Python < 50 %).
- Подробиці — CONTRACT §1.

## Правила

- Перед роботою: `git pull` на `main`, потім своя гілка `feat/...`.
- Пушимо тільки свою гілку. Ніколи не пушимо й не зливаємо `main`, ніколи не робимо force-push.
- Гейт Python: `ruff check pipeline tests tools && python tools/check_py.py && pytest -q`.
- Гейти гри: `node tools/engine_test.mjs` і `python tools/smoke.py game/index.html`.
- Коміти від свого імені, без жодних згадок AI.
